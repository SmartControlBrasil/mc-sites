Getting started

Arigo is a modern and professional React JS template designed for kindergarten schools, childcare centers, preschools, and other education-related websites. It offers a clean, user-friendly layout emphasizing your expertise and services, providing visitors with an exceptional online experience.

This is highly customizable and looks awesome on tablets and mobile devices. We have included best practices of web development and you can create a great website layout based on Bootstrap or Grid 1320px.

React Installation

Please follow the instructions in the video to see how you can install react on your hosting:

  1. For local host -
    1. Open your command prompt
    2. npm install or npm install --legacy-peer-deps
    3. npm run dev (will start the dev server at http://localhost:5173)

  2. For local build & preview -
    1. Open your command prompt
    2. npm run build or yarn build (will build the project and generate a dist folder in the root directory)
    3. npm run preview or yarn preview (will start the locally built server at http://localhost:4173)

  3. Deploying to Vercel - https://www.youtube.com/watch?v=_8wkKL0LKks
