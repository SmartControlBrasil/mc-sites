# Propriedade Intelectual do Frontend

O frontend estrutural do MC-SITES sera autoral.

A futura biblioteca interna de componentes, motion e interacoes sera proprietaria do projeto. Referencias visuais externas podem ser usadas como pesquisa de mercado, mas nao devem ser copiadas em codigo, convertidas diretamente ou incorporadas como base estrutural.

Componentes de terceiros nao devem ser adicionados sem auditoria de licenca e necessidade tecnica clara. Quando bibliotecas open source forem necessarias, suas licencas deverao ser verificadas antes da incorporacao.

Implementacoes proprias devem ser independentes, mesmo quando inspiradas por padroes comuns de mercado.
